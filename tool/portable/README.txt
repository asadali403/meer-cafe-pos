MEER CAFE POS - SETUP ON A NEW LAPTOP
=====================================

1. Right-click the zip file -> "Extract All..." -> Extract.
   (Do not run anything from inside the zip without extracting it first.)

2. Open the extracted "Meer Cafe POS" folder and double-click
   "Install Meer Cafe POS.bat".

   If Windows shows "Windows protected your PC", click "More info" -> "Run anyway".
   This appears because the app is not from the Microsoft Store; it is safe.

3. Done. The Meer Cafe logo is now on your Desktop (and in the Start Menu).
   From now on, just double-click the logo to open the app.
   You can delete the zip and the extracted folder afterwards.

No internet, admin password or extra software is needed.


MOVING YOUR DATA FROM THE OLD LAPTOP
------------------------------------
A new laptop starts with an empty database. To bring your products, users and
bills across:

  On the OLD laptop: sign in as admin -> Backup -> "Back up to USB / folder..."
                     and save the backup on a USB drive.
  On the NEW laptop: sign in as admin -> Backup -> "Restore from file..."
                     and pick that backup file from the USB drive.


UPDATING TO A NEWER VERSION
---------------------------
Close the app, then run "Install Meer Cafe POS.bat" from the newer zip.
Your data is kept (it is stored separately in %APPDATA%\MeerCafePOS).
